# Slime Eater – Forest Runner 3D (Game Design Doc ฉบับย่อ)

## Overview
เกมวิ่ง 3D มุมกล้องหลังตัวละคร 3 เลน (แนว lane runner) ในป่า สไลม์วิ่งไปข้างหน้าเอง ผู้เล่นเปลี่ยนเลน กระโดด สไลด์ หลบสิ่งกีดขวาง เก็บเหรียญ ครบ 1000 m เข้าฉากบอสพิมพ์ทายเงาสัตว์ (ระบบเดิม)

## Player Fantasy
สไลม์ตัวเล็กวิ่งฝ่าป่าที่ต้นไม้ล้มลงมาขวางทาง ต้องตัดสินใจเร็วว่าจะกระโดด สไลด์ หรือหลบไปเลนอื่น

## Detailed Rules
- เลน: 3 เลน (-1, 0, +1) ห่างกัน `laneWidth`
- ควบคุม: A/← ไปซ้าย, D/→ ไปขวา, Space/W/↑ กระโดด, S/↓/Shift สไลด์ (`slideDuration` วินาที)
- สิ่งกีดขวาง
  - ก้อนหิน (Low) – กระโดดข้าม หรือหลบเลน
  - ต้นไม้ล้ม (Falling) – ล้มขวางทางเมื่อเข้าใกล้ ส่วนลำต้นกระโดดข้ามได้ ส่วนพุ่มใบต้องหลบเลน
  - ท่อนไม้สูง (High) – พาดบนหินทุกเลน ต้องสไลด์ลอด
  - หินใหญ่ (Block) – สูง ข้ามไม่ได้ ต้องเปลี่ยนเลน
- ชน = เสียเลือด `obstacleDamage` + อมตะ `invincibleTime`
- เลือดลด `drainAmount` ทุก `drainEvery` เมตร (ลดทีละ 1 ให้เห็นค่อยๆ ลด)
- หัวใจฮีล +`healAmount` ทุก `healEvery` เมตร
- ช่วงแรก `firstSpawnAt` เมตรไม่มีสิ่งกีดขวาง, นับ 3 2 1 ก่อนเริ่ม/เล่นต่อ
- ครบ 1000 m → ฉากบอส (เลือด/เหรียญส่งต่อ)

## Formulas
- ความเร็ว = 1000 / `secondsToBoss` (m/s)
- ความสูงกระโดดสูงสุด = jumpVelocity² / (2 × gravity)

## Edge Cases
- เปลี่ยนเลนชนหินใหญ่ด้านข้าง = โดนชน
- กดสไลด์กลางอากาศ = ดิ่งลงเร็วแล้วสไลด์ต่อ
- ตกแมพไม่ได้: ความสูงถูกล็อกไม่ต่ำกว่าพื้น

## Dependencies
GameManager (state/HP), UIManager (HUD), WorldScroller (ความเร็ว), BossScene (ระบบทายเงาเดิม)

## Tuning Knobs
ทั้งหมดอยู่ใน `Assets/Data/RunnerConfig.asset`

## Acceptance Criteria
- เปลี่ยนเลน/กระโดด/สไลด์ได้ตามปุ่ม
- ต้นไม้ล้มเมื่อเข้าใกล้ และชนแล้วเสียเลือด
- วิ่งครบ 1000 m แล้วเข้าฉากบอส
